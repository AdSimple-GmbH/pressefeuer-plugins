# Pressefeuer-Plugins

Offizielle Plugins von [pressefeuer.at](https://pressefeuer.at) (AdSimple GmbH) für KI-Coding-Werkzeuge.
Sie verbinden das Werkzeug mit dem Pressefeuer-MCP-Server `https://pressefeuer.at/api/mcp`, damit
Agenturen Pressemitteilungen entwerfen, zur Kundenfreigabe senden und Berichte abrufen können.

| Plugin        | Werkzeug    | Ordner                                                                                                                    |
| ------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------- |
| `pressefeuer` | Claude Code | [`plugins/pressefeuer-claude`](https://github.com/AdSimple-GmbH/pressefeuer-plugins/tree/main/plugins/pressefeuer-claude) |

## Claude Code

```bash
claude plugin marketplace add AdSimple-GmbH/pressefeuer-plugins
claude plugin install pressefeuer@pressefeuer
```

Details, Anmeldung und Datenschutzhinweise stehen im README des jeweiligen Plugins.
